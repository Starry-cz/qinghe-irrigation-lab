# 第一版开发约定

视觉：浅灰白实验桌面、墨绿主色、设备剖面；以可操作的实验台为中心。
内容：学生登录→知识前测→观察猜想→设计测试→规则优化→验证解释→总结后测；教师负责名单、配置、进度和导出。
交互：水流、水泵和土壤读数随后端结果回放；阶段切换和指导消息短过渡，支持减少动画。

复用项目：Rediwed/react-express-template（MIT）提供前后端结构；NDilanka/agri-sim（Apache-2.0）提供水量平衡模块。见 THIRD_PARTY.md。

本次暂定一人一账号。四种条件可逐人指定，也可按班级/前测排序形成四人区组后随机分配；正式方案待研究者确认。
湿度暂定0–4095，越大越湿；初始阈值2800，不考虑天气；参考规则为在初始规则上加入预报有雨不灌溉。参考规则仅用于教师侧分析，不等于真实植物的最优规则。
二维设备仿真，可设初始读数、预报、实际降雨、连接状态和控制规则。没有真实硬件通信、任意接线电路或任意代码执行。
初次猜想前默认禁用指导；主动组可求助。停留120秒、重复3次相同测试等触发一次指导；每阶段每种自动触发类型最多一次，冷却45秒。异常通过测试前结构化预测与实际决策不一致判断，不宣称能从自由文本准确识别全部困难。
五个阶段后四阶段为本次补充设计：阶段1至少2次测试；阶段2保存规则并至少测试一次；阶段3至少2次且覆盖不同条件；阶段4提交总结与后测。
每人首次进入保存配置快照；修改教师配置不会改变已开始学生的快照。学生分组开始后锁定。模型服务是部署级设置，变更模型应开启新一轮实验；模型标识记入调用事件。
默认源码提供明确的scripted教学模式；本地已按用户授权配置DeepSeek真实接口。接口失败明确显示，保留已提交实验数据，不替换为另一种反馈模式。

验收：前后端构建运行；五阶段闭环和刷新恢复；教师名单、配置、档案和导出；四条件隔离；重启持久化；部署文件及说明。
