# 设备识别图说明

日期：2026-10-28。复用并调整原有SVG设备组件，登录页、观察记录和实验工作台共用同一套设备绘制。无需新增图片服务或图形库。

## 设备和连接

- 储水箱、水泵、控制器、水泵驱动、土壤湿度探头、实验花盆共六类设备，可点击图形、标签或下方设备按钮查看说明。
- 水路沿下方从储水箱经水泵到花盆出水口；控制器与驱动、水泵按竖直方向连接；探头信号沿上方和右侧回到控制器。三条主路径不交叉。
- 水路以粗蓝线和方向箭头表示，控制/驱动以金色细线表示，探头信号以绿色细线表示。连接断开时出现缺口、虚线和断开标记。
- 探头探测段、植物根系画在土壤剖面内部；电子头部在土壤上方。水箱液位保持示意，明确默认水源充足，不凭空模拟水箱容量。读数不标成未经标定的真实含水率。
- 这是功能连接图，电源与公共接地省略。驱动模块用于表达控制器与电机之间的驱动关系，并未新增实验参数或独立的驱动故障模型。

设计核对参考：[Arduino官方电机驱动说明](https://docs.arduino.cc/learn/electronics/transistor-motor-control)、[SparkFun电机驱动说明](https://learn.sparkfun.com/tutorials/driving-motors-with-arduino/all)、[DFRobot电容式土壤传感器说明](https://wiki.dfrobot.com/sen0193/docs/18035)。这些资料用于核对概念，未复制其产品图或接线图。

## 数据和操作

- 登录页显示示例设备状态；观察页用静态图表达记录A/B/C的实际决策，不播放真实测试动画。
- 工作台只有在模拟运行且该时刻水泵开启时，才转动泵轮、显示流动与滴水；停止后保留最终读数与累计供水。
- 天气预报和实际降雨独立呈现，仅在实际降雨的测试运行期间显示雨滴。
- 回放读数、天气、连接均来自历史记录，下方输入仍是下一次测试设置。
- 放大视图、窄屏横向查看、设备定位、Enter/空格选择、Esc关闭均可用。SVG实例使用独立资源ID，避免普通视图与放大图互相干扰。

## 验证

构建成功。独立测试数据库下实际检查六类设备选择、键盘选择、供水、探头断开、水泵断开、实际降雨、仅预报有雨、历史回放及A/B/C观察记录。断开时供水为0；正常测试供水350mL；模拟停止后停止流水动画。

登录与工作台在1920、1440、768、390px宽度下没有整页横向溢出。小屏图内部可横向查看；放大定位不会滚动背后页面。截图与浏览器检查记录在本机output/playwright，未改变原实验数据。
