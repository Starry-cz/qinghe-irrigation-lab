# 青禾页面视觉规范

设计方向：中性浅灰与白色营造清楚的工作界面，深灰正文保持可读，森林绿延续植物实验的品牌；用字号、对齐和空间建立层级。

内容安排：首页保留登录/注册与可操作设备图，主要行动仍是进入实验；学生页按阶段、实验工作区、指导区组织；教师页按导航、数据和操作组织。此前删除的首页页脚与图下说明不恢复。

交互安排：保留短暂的首页入场；按钮按压、选中和键盘焦点提供明确反馈；弹窗进入有轻量过渡。实验动画继续表示设备状态。减少动态效果设置下关闭过渡，不增加滚动劫持、视差或装饰循环动画。

参考与取舍：

- [Apple 中国官网](https://www.apple.com.cn/)：学习产品视觉的主次关系、克制用色和排版；不复制商标、产品图片或整页营销布局。
- [shadcn/ui 的 Button 源码](https://github.com/shadcn-ui/ui/blob/main/apps/v4/registry/new-york-v4/ui/button.tsx)：参考按钮状态、焦点和变体的统一方式，未引入整套组件依赖。
- [Radix Colors 浅色源码](https://github.com/radix-ui/colors/blob/main/src/light.ts)：实际复用 gray、green 两组颜色刻度，MIT许可随源码保留。品牌主色保留现有森林绿，避免白色按钮文字落在过浅的绿色上。
- 使用本机 frontend-skill 和 ui-ux-pro-max；检索结果中的低对比拟物阴影不适合课堂长时间阅读，故不采用。外文科技字体组合也不适合中文主体，使用系统中文无衬线字体。

全局正文16px；核心实验输入、表单和指导正文16px；表格与常规操作15px；辅助信息13–14px。工作页主标题30–36px，首页标题随屏幕34–64px。数字用等宽数字排列；只有设备读数和代码资料采用等宽字体。

交互控件保持至少44px的主要点击高度。浅色主题采用深灰文字和白色/浅灰底；默认文字组合检查4.5:1对比度。移动端通过换行与布局调整适配，不靠缩小正文或禁止缩放。

实现主要集中在 styles/tokens.css、App.css 和三个组件样式文件，不修改实验流程、API或模型设置逻辑。

## 首页一屏适配（2026-11-03）

延续中性背景和森林绿，用可用屏幕高度控制首页标题与设备预览图的比例。内容仍是登录区与设备识别区，保留部件选择和放大查看，不新增动画。

仅在电脑登录首页调整顶部、表单和设备卡片的纵向间距；预览SVG保留完整图形并设置随视口高度变化的上限。选择器限定首页主图，不影响学生实验工作区或设备放大弹窗。输入框和主按钮保持48px高度，主要点击目标保持44px以上。没有通过隐藏溢出裁掉底部内容。

Chrome实测学生/教师两种登录入口，在1920×950、1920×900、1536×864、1440×800、1366×768、1366×650、1280×720和1024×768视口下，文档高度均等于视口高度；六种设备说明切换与登录错误提示也可完整显示。注册长表单与手机维持自然滚动。构建及同源烟测通过，截图在 `output/playwright/home-fit-*`。
