# 自主注册与管理员审核

## 学生和教师怎么使用

1. 在登录页选择学生或教师身份，点击“自主注册”。
2. 学生填写真实姓名、学号、班级；教师填写真实姓名、登录账号、至少 8 位密码，并可补充任教信息。
3. 提交后等待管理员审核。申请不会自动登录；学号或教师账号重复时提示使用已有账号。
4. 审核通过后，学生使用姓名和学号登录，教师使用账号和密码登录。待审核或未通过时，登录页会显示相应提示；未通过会显示管理员填写的原因。

当前没有邮件或短信通知。申请人可从登录入口查看是否已获准登录；资料需要纠正时联系管理员，未通过的申请可重新审核通过。

## 管理员怎么审核

`admin` 登录后打开“注册审核”。导航上显示待审核数量；支持按审核状态、身份、姓名或账号筛选。可逐个处理，也可勾选多位申请人后一起通过或拒绝。列表覆盖平台的全部申请，不局限于某一轮实验。

通过包含学生的申请时，选择开放中的实验和实验条件。可以指定一种条件，或选择按该实验当前各组人数均衡分配。均衡分配只是临时安排，不能替代研究方案要求的随机分组；如需调整，请在学生首次登录前完成。教师申请无需指定实验，通过后可共同管理实验与名单。

拒绝时填写原因。审核记录保存申请时间、审核人、审核时间和说明；已通过的申请不重复审批。批量审核中若某项已被其他管理员处理，或实验不再开放，整批不会部分保存，刷新后重新选择即可。

## 原有名单导入

教师仍可直接添加或批量导入新学生；已开通学生也可继续加入其他实验。若学号已经对应待审核或未通过的申请，导入会提示先由管理员审核，不能借导入激活账号。

只有管理员可以直接创建教师账号、审核注册和查看全部账号。普通教师可管理实验、导入学生、查看已开通的学生资料、修改自己的姓名和密码。

## 数据保存

用户资料和审核记录存入 SQLite，重启不会丢失。教师密码继续使用 bcrypt 保存；接口和用户表格不返回密码摘要。审批学生时在同一事务中保存审核结果和实验报名，确保通过后可以直接登录。

升级时已有账号均保持已开通状态，原学生报名 ID、实验进度、提交与测试记录保留。先执行 `npm run backup`，再启动新版本完成自动迁移。
